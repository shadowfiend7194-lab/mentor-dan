# 🧠 Discipline Mentor (Дэн)

AI-наставник для развития дисциплины, привычек и достижения целей.

## 🚀 Возможности

- ✅ Онбординг пользователя
- ✅ Постановка целей
- ✅ Полезные привычки
- ✅ Нежелательные привычки
- ✅ Настройка периодичности
- ✅ Отслеживание выполнения
- ✅ Система прогресса

## 🛠 Технологии

- Python
- python-telegram-bot
- SQLite

## 📌 Версия

v1.0 Stable

## 🎯 Идея

Дэн помогает пользователю становиться лучше через маленькие ежедневные действия и систему дисциплины.
