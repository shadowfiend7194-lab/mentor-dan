# MENTOR DAN — BLOCK 7

## После замены файлов

Останови бота через Ctrl+C.

### Полный сброс тестовой базы Windows PowerShell

Если база лежит в корне проекта:

```powershell
Remove-Item .\dan.db -Force
```

Если хочешь сначала проверить наличие:

```powershell
Test-Path .\dan.db
```

После удаления запускай бота заново — база создастся заново, и пользователь будет проходить онбординг как новый.

ВАЖНО:
- `.env` НЕ удалять.
- `.git` НЕ удалять.
- удаляется только `dan.db`.

### Установка зависимостей

```powershell
pip install -r requirements.txt
```

### Проверка PRO отчёта

```text
/reporttest
```

Показывает последнюю полностью завершённую неделю (понедельник–воскресенье).

Чтобы увидеть новый дизайн прямо на текущей неделе, не дожидаясь воскресенья:

```text
/reporttest_current
```

Этот тест строит отчёт с понедельника текущей недели по сегодняшний день.

### Что проверить

1. 🎯 Моя цель
2. Изменить цель
3. Выбрать конкретную цель
4. Изменить название
5. Удалить цель
6. Изменить привычку
7. Название → карточка привычки
8. Периодичность → карточка привычки
9. Сложность → карточка привычки
10. Цель → карточка привычки
11. Мотивация → карточка привычки
12. /reporttest_current

Формулировки интерфейса и словесные уровни сложности сохранены.
